Ajuda do AD User Creator — ISO27001.hlp

Documentação Técnica e de Segurança

Classificação: Uso Interno | Conformidade: ISO/IEC 27001

1. Visão Geral do Sistema

O AD User Creator automatiza o provisionamento e desabilitação de identidades e acessos (IAM) de forma segura. O sistema opera 100% local (Air-gapped) e não armazena credenciais em banco de dados.

3. Segurança no Desenvolvimento (DevSecOps)

O código-fonte incorpora práticas rígidas para impedir ataques cibernéticos comuns:

  • Command Injection: Entradas de formulário e CSV são sanitizadas rigorosamente via escapePS(), envelopando dados em strings literais seguras para o PowerShell.
  • Cross-Site Scripting (XSS): Toda exibição de dados vindos do AD passa por escapeHTML() para evitar injeção de scripts maliciosos no browser.
  • CSRF e Proteção de Rede: O micro-serviço (Server.ps1) executa exclusivamente no endereço de loopback 127.0.0.1 e valida tokens de requisições de origem única (CORS), bloqueando chamadas externas da internet.

4. Trilhas de Auditoria (Event Logging)

Toda criação ou desabilitação de contas gera logs de segurança oficiais nos Controladores de Domínio (Domain Controllers) associados ao SID do analista logado:

  • Event ID 4720: Registro de criação de conta de usuário.
  • Event IDs 4728/4732: Alteração de membros de grupos de segurança (rastreabilidade de acessos espelhados).
